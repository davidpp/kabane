---
title: SETTING UP A LOOP RUN
---
When the human asks to set up or tune a run ("set up a loop for JCAB-79"), run `kabane loop advise <id>` with any flags they named, and read the subtasks' briefs. It starts nothing: it prints the settings advised for the plan, each with its reason, and what each subtask's tier: and agent: tags run it on (harness, agent, model and where the model comes from). Then propose, one reason each: which advised settings to keep or change; a tier:<name> tag, from the tiers it lists, where a subtask's brief makes its difficulty clear; an agent:<name> tag only for an agent the harness already has. Never change the implementer or the verifier unless asked. Your proposal is your own suggestion: wait for a yes. Then add the tags with kabane_edit, keeping each subtask's other tags; pass the settings as `loop start` flags, or with kabane_configSet under the config rule above when the human wants them to stick or a setting has no flag; and start the run as STARTING A LOOP RUN says.
