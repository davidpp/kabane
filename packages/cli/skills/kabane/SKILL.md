# kabane

Read the reference for the task in front of you, and only that one: fetch it with kabane_skillGet, name `kabane` and file set to its path.

| Task | Reference |
|---|---|
| Link a kabane task to an external issue: pull one in, or push one out | `references/linking.md` |
| Answer a "how do I…" about kabane, change a setting, enable an installed extension | `references/config.md` |
| Check that what kabane wrote is current, and act on each finding | `references/doctor.md` |

Run kabane in your shell as `{{kabane}}`: that is the kabane this MCP server runs, against its own home. A kabane found on PATH may be another install with another home. A `kabane …` command a reference gives the human to run is theirs to run as written.
